# Terminal Chess 

A command-line chess game written in Go, powered by the Stockfish UCI engine. Play against a computer opponent from your terminal with customizable difficulties, turn time limit controls, and color selection.

## Prerequisites

Before running the application, ensure you have the following installed:
1. **Go** (version 1.18 or higher)
2. **Stockfish Chess Engine** (must be installed and available in your system's `PATH`)
   - **macOS:** `brew install stockfish`
   - **Ubuntu/Debian:** `sudo apt install stockfish`
   - **Windows:** Download from the official Stockfish website and add it to your environment variables.
